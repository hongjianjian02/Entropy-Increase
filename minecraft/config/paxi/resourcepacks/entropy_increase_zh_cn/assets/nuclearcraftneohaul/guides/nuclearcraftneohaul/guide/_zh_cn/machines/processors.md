# 加工机器

这些机器通常消耗能量来加工材料，将其转化为其他材料。

| 加工机器                           | 说明                                                                                                                                          |
|-------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| <ItemLink id ="nuclear_furnace" />  | 以铀锭或铀粉为燃料，快速熔炼物品                                                                                           |
| <ItemLink id ="alloy_furnace" />    | 将基础金属熔合为合金                                                                                                            |
| <ItemLink id ="assembler" />        | 将部件组合成复杂的成品                                                                                                           |
| <ItemLink id ="centrifuge" />       | 从流体材料中分离同位素                                                                                                            |
| <ItemLink id ="chemical_reactor" /> | 为流体之间的化学反应提供反应空间                                                                            |
| <ItemLink id ="crystallizer" />     | 从流体中析出固体                                                                                                                     |
| <ItemLink id ="decay_hastener" />   | 加速放射性材料衰变，使其转化为其他同位素或材料；衰变过程会释放辐射 |
| <ItemLink id ="electrolyzer" />     | 将流体分解为其组成成分                                                                                                           |
| <ItemLink id ="fluid_enricher" />   | 将材料加入流体中                                                                                                                             |
| <ItemLink id ="fluid_extractor" />  | 从材料中提取流体                                                                                                                       |
| <ItemLink id ="fluid_infuser" />    | 向材料中灌注流体                                                                                                                             |
| <ItemLink id ="fluid_mixer" />      | 混合多种流体                                                                                                                                |
| <ItemLink id ="fuel_reprocessor" /> | 从枯竭燃料中分离并提取可利用的材料                                             |
| <ItemLink id ="ingot_former" />     | 将熔融材料制成锭或宝石                                                                                                           |
| <ItemLink id ="manufactory" />      | 一台多用途机器，主要用于材料加工                                                                                         |
| <ItemLink id ="melter" />           | 将材料熔化成液体                                                                                                              |
| <ItemLink id ="pressurizer" />      | 在极高压力下加工材料                                                                                                           |
| <ItemLink id ="rock_crusher" />     | 粉碎岩石，获得矿物粉末                                                                                                               |
| <ItemLink id ="separator" />        | 将材料分离为其组成成分                                                                                                     |
| <ItemLink id ="supercooler" />      | 降低流体的温度                                                                                                                     |
